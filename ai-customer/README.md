# ai-customer

Uni AI API 用户端门户。

## 启动

```bash
bun install
bun run dev
# http://localhost:13013
```

## 环境变量

- `VITE_APP_TITLE`
- `VITE_PROXY_BASE_URL`
- `VITE_SSO_AUTHORIZE_URL`
- `VITE_SSO_CLIENT_ID`
- `VITE_SSO_CLIENT_TYPE=customer`

## 主要功能

- ✅ AI 路由浏览与文档
- ✅ API Key 管理
- ✅ 余额与套餐
- ✅ 消费统计
- ✅ 访问日志
- ✅ SSO 授权登录
- ✅ Token 自动刷新

## 技术栈

- Vue 3 + Vite
- Element Plus
- Tailwind CSS
- Pinia
- Vue Router
- Axios
