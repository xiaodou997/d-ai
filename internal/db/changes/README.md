# 数据库人工变更

`../init.sql` 是全新 D-AI 数据库的完整结构。应用不会执行迁移或升级 SQL。

已有环境无法直接重建时：

1. 增加经过评审的单向脚本，命名为 `YYYYMMDD_description.sql`。
2. 在同一个改动中同步更新 `../init.sql`，保证它始终代表最终完整结构。
3. 在维护窗口人工执行变更脚本。
4. 在变更脚本和 `../init.sql` 中递增 `dai_schema_metadata.version`，同时更新 Go 中的期望版本。
5. 分别在空数据库和目标环境副本上验证。

不要加入迁移框架标记，也不要把这些脚本接入应用启动流程。
